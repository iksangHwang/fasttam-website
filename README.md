# FastTam Website

Static marketing / support / privacy site for **FastTam — fasting & diet** iOS app.

Hosted on Vercel: https://fasttam.vercel.app

## Pages

- `/` — Marketing (landing)
- `/support` — Customer support & FAQ
- `/privacy` — Privacy policy
- `/app-ads.txt` — AdMob app ownership verification

## Local preview

```bash
npx serve .
```

## Deploy

Auto-deployed on push to `main` via Vercel Git integration.
